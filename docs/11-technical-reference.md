# 11 — Technical Reference

Quick lookups for specific values. See the linked numbered docs for explanations.

## Ports

| Port | Protocol | Purpose | Doc |
|---|---|---|---|

## `takserver.env` variables

| Variable | Meaning |
|---|---|
| `TAK_SERVER_ADDRESS` | Server address embedded in client packages |
| `TAK_SERVER_NAME` | Display name shown in the client package |
| `POSTGRES_PASSWORD` / `POSTGRES_USER` / `POSTGRES_DB` / `POSTGRES_ADDRESS` | DB access |
| `CA_NAME` / `CA_PASS` | Certificate authority |
| `TAKSERVER_CERT_PASS` | Server certificate password |
| `ADMIN_CERT_NAME` / `ADMIN_CERT_PASS` | TAK administrator certificate |
| `COUNTRY` / `STATE` / `CITY` / `ORGANIZATION` / `ORGANIZATIONAL_UNIT` | CA certificate metadata |
| `DOCKER_SOCKET_GID` | Docker socket group ID (set by the installer) |
| `LOGGING_JSON_ENABLED` / `LOGGING_CONFIG` | JSON logging format |
| `ADMIN_SECRET_KEY` | JWT signing secret (generated by the installer) |
| `ADMIN_FIRST_USER` / `ADMIN_FIRST_PASS` | First superadmin account (password erased after first boot) |
| `TAK_BASEMAP_PROXY_ENABLED` / `TAK_BASEMAP_PROXY_URL` / `TAK_BASEMAP_CACHE_MAX_MB` / `TAK_BASEMAP_OFFLINE_PUSH_MAX_MB` / `TAK_BASEMAP_AOI_MAX_TILES` | Basemap gateway |
| `BASEMAP_SERVICE_CERT_NAME` | Service certificate for the basemap gateway |
| `OIDC_ISSUER` / `OIDC_CLIENT_ID` / `OIDC_CLIENT_SECRET` / `OIDC_PROVIDER_NAME` / `OIDC_SCOPES` / `OIDC_GROUPS_CLAIM` / `OIDC_DEFAULT_ROLE` / `OIDC_ROLE_MAP` / `OIDC_REDIRECT_URL` / `OIDC_POST_LOGIN_URL` | Optional SSO — empty value = disabled |

Full commented template: `takserver.env.example`.

## `make` commands

| Command | What it does |
|---|---|
| `make build` / `up` / `down` / `restart` | Container lifecycle |
| `make update` | Runs `update.sh` |
| `make add-user USERNAME=x-iTAK` | Cert + package + authorization in one step |
| `make gen-device-cert` / `make-package` / `gen-cert` / `enable-user` | Granular user-creation steps |
| `make list-packages` / `serve-packages` | Package listing / server info |
| `make add-plugin APK=...` / `list-plugins` | Client plugins |
| `make install-plugin JAR=...` | Server plugin |
| `make add-service NAME=x` | Certificate for a machine integration |
| `make logs` / `logs-db` / `status` | Monitoring |
| `make shell` | Bash into `takserver_config` |
| `make generate-lockfile` | Generates `admin/ui/pnpm-lock.yaml` via Docker |

## Roles (admin panel)

| Role | Access |
|---|---|
| `superadmin` | Everything, including user management, logs, audit log, shell |
| `admin` | Users, packages, plugins, maps — no system administration |
| `readonly` | View only |
| `field` | Download own packages only |

## Client type suffixes

`USERNAME` always ends in `-ATAK`, `-WinTAK`, `-iTAK`, or `-Service` (the latter for automated integrations, not a TAK client).
