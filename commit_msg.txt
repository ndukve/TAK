release: v1.0.8 — add TAK basemap distribution and resilient map operations

- add a basemap gateway for cataloging, proxying, caching, previewing, and distributing online and offline map layers to connected TAK clients
- publish selected basemaps through TAK Server mission APIs with recipient targeting, delivery history, resend, cleanup, and service-certificate management
- add bounded AOI downloads that generate offline MBTiles packages with validation, storage limits, progress reporting, and smoke-test coverage
- fix the admin live map by allowing its CARTO tile source, repairing service-certificate routing membership, and returning readable connection failures
- add chunked map uploads with visible progress, pause and resume controls, persisted server offsets, atomic finalization, and SHA-256 verification
- keep efdi-bridge certificates permanently enabled with TAK-USERS IN + OUT routing access and repair their assignment during updates
- protect always-on EFDI bridge identities from disable, delete, and purge operations while identifying them clearly in the admin UI
- update deployment settings, volume preparation, documentation, and automated tests for the new basemap and map-transfer workflows
